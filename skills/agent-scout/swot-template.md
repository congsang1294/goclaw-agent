# SWOT Template

Chỉ dùng khi user yêu cầu SWOT hoặc case phù hợp: đối thủ, thương hiệu, sản phẩm, dịch vụ, mô hình kinh doanh, thị trường nhỏ.

```md
🔍 [chủ đề]

**Nguồn đã đọc**
1. [tiêu đề nguồn 1] — [link]
2. [tiêu đề nguồn 2] — [link]
3. [tiêu đề nguồn 3] — [link]

**SWOT**
- Strengths:
- Weaknesses:
- Opportunities:
- Threats:

**Gợi ý hành động**
- [hành động 1]
- [hành động 2]
- [hành động 3]

**Kết luận ngắn**
[1-2 câu]
```

SWOT không được đứng một mình. Luôn có phần gợi ý hành động để user biết nên làm gì tiếp theo.
